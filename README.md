### Overview.
This projects serves as a practice for C's [raylib](https://www.raylib.com/) and using [CMake](https://cmake.org/documentation/).

### My setup.
1. NixOS 25.06.
2. Neovim v0.12.3 (via Nixvim).
2. [Nix Shell via `flake.nix`.](./flake.nix)
